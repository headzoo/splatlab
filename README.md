# Chickensplat Monorepo

This workspace is organized as a pnpm monorepo.

- `apps/game` contains the Splat Lab! game assets, specs, tools, maps, and tests.
- `apps/website` contains the Vercel-hosted Next.js website.

Run website commands from the repo root with pnpm:

```bash
pnpm dev
pnpm build
pnpm lint
pnpm typecheck
```
